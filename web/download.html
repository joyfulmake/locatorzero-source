🛡️ Your system will ask once, and that's expected

These installers are not code-signed yet (certificates are on the way), so Windows and macOS show a warning the first time. Compare the SHA-256 fingerprint below with the downloaded file to be sure it's ours.

Verify your download

The fingerprint of your file must match the one listed above, character for character.

Windows (PowerShell)
Get-FileHash .\LocatorZero_*-setup.exe -Algorithm SHA256
macOS (Terminal)
shasum -a 256 ~/Downloads/LocatorZero_*.dmg
Linux
sha256sum LocatorZero_*.deb

All fingerprints in one file: SHA256SUMS.txt

Optional: check our signature

That file is signed with the LocatorZero release key, so you can prove it came from us:

gpg --import locatorzero-release-key.asc
gpg --verify SHA256SUMS.txt.asc SHA256SUMS.txt

Requirements

  • Windows 10 or 11, 64-bit. On Windows 10, the installer may fetch Microsoft's WebView2 component if it's missing; Windows 11 already has it.
  • macOS 10.13 or later, Apple silicon or Intel.
  • Linux with WebKitGTK 4.1: Ubuntu 22.04+, Debian 12+, Fedora 36+ and similar.

What you get

  • Search this computer, USB and network drives, cloud folders, browser history and open tabs at once.
  • A consent question before each place is searched. Nothing is read without your OK.
  • Locations and Map views, preview on request, and "Show in folder".
  • Free for 90 days. Then $3 a month, $25 a year, or $35 once for version 1. The store opens soon.

Privacy, in one paragraph

Downloading is an ordinary request to our host, Cloudflare. After that, LocatorZero never connects to the internet: no account, no tracking, no update checks. It keeps no copy of what it finds and forgets your searches when you close it. Try the browser version and press Verify to watch the checks run live.
