        Privacy checks, run live

        These run in your browser right now. Nothing here is a screenshot or a promise.

          Check it yourself, without trusting this page
          1. Open your browser's developer tools, choose the Network tab, then search and preview. No request appears after the page loads.
          2. Turn on airplane mode and reload. The app keeps working from its offline cache.
          3. Loading the page is an ordinary request to the host, Cloudflare Pages. That is the only request, and it carries nothing you typed.
          4. In the source, run desktop/check-no-network.sh: it lists every library the app is built from and fails if any can talk to a network.

          Source available: anyone may read and audit the code that makes these promises. The desktop app is free for 90 days, then needs a licence key, which is checked offline.
